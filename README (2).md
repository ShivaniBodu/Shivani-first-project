# 🔐 Smart Password Generator

A Python project that generates strong, random passwords with a strength checker!

## ✨ Features
- Generate passwords with custom length (8–32 characters)
- Choose to include uppercase letters, numbers, and symbols
- Password strength checker (Weak / Medium / Strong)
- Auto-copy password to clipboard

## 🚀 How to Run

```bash
pip install pyperclip
python password_generator.py
```

## 📸 What it does
- You pick the length and options
- It creates a secure random password
- Tells you if it's Weak, Medium, or Strong
- Copies it to your clipboard automatically!

## 🛠️ Built With
- Python 3
- `random` module
- `string` module
- `pyperclip` library
